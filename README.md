# Massive Business Growth — website

## Project structure
- `index.html` — the complete website (HTML, CSS and JavaScript)
- `media/` — images, posters and videos used by the website

Keep `index.html` and the `media` folder together.

## Open locally
Double-click `index.html` or open the project folder in VS Code and use a local preview/server.

## Netlify
Upload the **whole project folder**, not just `index.html`:

- `index.html`
- `media/`

If you upload only `index.html`, the images, posters and videos will not be found.
